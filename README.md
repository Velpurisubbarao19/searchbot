# searchbot
🧠 SearchBot - Your Thoughtful AI Companion
SearchBot is a warm, emotionally intelligent chatbot interface built with OpenAI's GPT model and Gradio. It responds like a caring friend, adapting to your emotional tone, and supports both dark and light themes for an enhanced user experience.


⚙️ Features
🧑🤖 Emotionally-aware AI responses

🌓 Light/Dark mode toggle

💬 Chat history tracking

🎨 Custom themed UI with Gradio

🔒 Secure OpenAI API integration
